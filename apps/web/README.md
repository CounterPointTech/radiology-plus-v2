# Radiology Plus Web (Next.js)

Frontend for Radiology Plus v2.1.

- Next.js App Router (latest)
- Tailwind CSS v4
- Motion (Framer Motion) + React Spring
- TypeScript strict

```bash
npm install
npm run dev    # http://localhost:3000
```

See `app/globals.css` for the design tokens — distinct brand with deep neutrals,
teal-leaning blue accent, warm coral cautions, and a sparing NovaRad red nod.
